## Description
Is repository mein mere COAL ke assignments ke 8086 assembly programs hain. Har assignment apne alag folder mein hai.

## Tools Used
- NASM (assembler)
- DOSBox (emulator)

## How to Assemble and Run
1. DOSBox mein folder mount karo:
```
   mount c C:\path\to\COAL-Assembly-Programs
   c:
```
2. Program assemble karo:
```
   nasm Assignment1\q1.asm -o q1.com
```
3. Run karo:
```
   q1.com
```
